Minecraft 1.21.11 / Fabric / Java 21 - ПОЛНОЦЕННЫЙ мод (сервер + клиент)

Работает в одиночной игре и на своём сервере НА FABRIC (не на Purpur/Paper -
там нужен отдельный плагин lumberjack_plugin, он уже есть отдельно).

КАК ПОЛЬЗОВАТЬСЯ:
 Переименуйте ЗОЛОТОЙ топор в наковальне в «Топор дровосека».
 - Топор один в руке: ПКМ в воздух - рывок вперёд.
 - Топор в основной руке + обычное огниво в другой руке: ПКМ - поджигает
   воспламеняемые блоки в радиусе 4 вокруг вас (круглая область, с эффектом
   огненных частиц по кругу). Огниво при этом теряет прочность и может
   сломаться, как при обычном использовании.
 Перезарядка обеих способностей - 1 секунда.

СБОРКА: через GitHub Actions (.github/workflows/build.yml) или ./gradlew build.
Готовый jar: build/libs/lumberjack-2.1.1.jar -> в папку mods (и на сервер,
и на клиент, если это ваш отдельный Fabric-сервер; на клиент одиночной игры
достаточно положить в mods один раз).

Настройки: LumberjackMod.java (AXE_NAME, DASH_POWER, IGNITE_RADIUS, COOLDOWN_TICKS).
